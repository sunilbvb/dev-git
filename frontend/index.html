📖 Gitflow Strategy & Release Guide

1. Permanent Primary Branches

  • main: Stable production-ready code. Commits are tagged.
  • develop: Integration branch. Gathering place for completed features.

2. Supporting Branches (Temporary)

Type Source Merge Target Purpose
feature/vX.X.X/* develop develop Developing new features in isolation.
release/vX.X.X/* develop main & develop Preparing release; bug fixes & docs only.
hotfix/vX.X.X/* main main & develop Emergency fixes for critical prod bugs.
bugfix/vX.X.X/* develop develop Minor non-critical bug fixes.

3. Standard Lifecycle

  1. Initialize develop from main.
  2. Create feature/* from develop → merge back when done.
  3. Initiate release/* from develop.
  4. QA Testing on release → Merge to main (tag it) & develop.

4. Testing & Bug Management

Internal Testing Integration: Quality checks happen inside the release branch. Build appbundle/IPA from release branch. Tester bugs are resolved directly on release branch. Merge to main only after green signal.

Hotfix vs. Bugfix: Critical production bugs use hotfix/ (branched from main). Minor UI/typo fixes use bugfix/ (branched from develop, deferred to next release).

🚀 Git Release Workflow: v1.1.x

Option 1: The Terminal (Fast & Local)
git checkout main
git pull origin main
git tag -a v1.1.4 -m "Release version 1.1.4"
git push origin v1.1.4
Option 2: GitHub Releases (Formal & Public)
  1. Go to Releases in GitHub → "Create a new release".
  2. Type version (e.g., v1.1.4).
  3. Release Title: e.g. v1.1.4 - The UI Update.
  4. Generate release notes, polish with sections:
    • ✨ New features
    • 🐛 Bug fixes
    • ⚠️ Breaking changes
  5. Upload compiled APK/bundles → Click "Publish release".

📄 Readme

🔄 DevGit — Standalone Multi-Repo Git Dashboard

A lightweight, zero-dependency, local web-based dashboard designed for managing Git repositories across monorepos, multi-repo projects (apps/, packages/, tools/), and standalone workspaces.

Quick Start
./start.sh --open
Opens at http://localhost:8086
Custom Workspace
./start.sh --workspace /path/to/monorepo

For full documentation see the project GitHub repository and the User Guide & Walkthrough.

⚙️ Installing

Method 1 — Run directly (no install needed)
git clone https://github.com/sunilbvb/dev-git.git
cd dev-git
./start.sh --open
Method 2 — Install as a CLI tool
pip install .
devgit --open
Method 3 — Target a specific workspace
./start.sh -w /path/to/my-monorepo -p 8086 --open
💡 No npm, no Node.js, no pip packages required for the standard run method. The backend uses only Python standard library.

✨ Features

🔍
Automatic Repository Discovery
Scans monorepos, multi-repo structures (apps/, packages/, tools/, services/, libs/), and custom layouts via .devgit.json.
📊
Multi-Repo Status Grid
Visual grid overview of dirty working trees, untracked changes, ahead/behind tracking against remote branches.
⚡
Batch Git Operations
One-click Fetch All across all repos. Sync, branch creation, fast-forward pulls, pushes, and stash management.
🤖
AI-Powered Commit Messages
Generate semantic Conventional Commit messages using local Ollama models (llama3, deepseek-r1, mistral). Fully private.
🌿
Gitflow Branch & Release Management
Visual Gitflow branch creation, finish/merge, checkout, deletion. Tag creation, SemVer bumping, and GitHub release summaries.
💻
Embedded Interactive Terminal
Run Git commands directly within specific repositories from the web UI. No IDE or terminal switch required.
📦
Stash & Worktree Managers
Inspect, create, apply, and prune stashes and worktrees through a dedicated UI modal with keyboard shortcuts.
⌨️
Full Keyboard Shortcut System
Ctrl+K search, R refresh, F fetch, S stash, T worktrees, C copy standup, W switch workspace, Esc close, ? help.

🎯 Use Cases

📱
Flutter Melos Monorepos
Manage apps and packages in a Melos-powered Flutter workspace. DevGit understands Melos branch naming conventions and creates synchronized multi-repo branches automatically.
🏗️
JavaScript Turborepo / pnpm Workspaces
Oversee frontend apps and shared packages in a Turborepo. Track dirty states and sync branches across all packages from one dashboard.
🔬
Microservices Architecture
Keep track of dozens of independent service repositories simultaneously — spot which services have uncommitted work before a release cut.
🧑‍💻
Solo Developer Workflow
Replace multiple terminal tabs. Get a bird's-eye view of your personal projects, create Gitflow branches, write AI-assisted commits, and copy standup summaries.
🏢
Team Stand-Up Reporting
Use the Copy Standup Summary feature (hotkey C) to instantly generate a Markdown report of dirty repos and active branches ready to paste into Slack or Notion.
