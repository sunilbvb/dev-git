## Quick Overview

DevGit is a standalone, multi-repository Git dashboard providing:
- Multi-repository workspace discovery.
- Safe terminal execution with subcommand allowlisting and argument sanitization.
- Branch, stash, release, and conflict management UI.
- Secure local authentication token and CORS origin enforcement.

Refer to the main [README.md](../README.md) for full configuration, setup instructions, and feature details.
